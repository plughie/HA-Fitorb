# App icon artwork

The Fitorb Relay app icon is an original illustrated adaptation generated for
this project. Its visual reference was the following Creative Commons image:

- **Source:** [Bezahlring.jpg](https://commons.wikimedia.org/wiki/File:Bezahlring.jpg)
- **Creator:** Johann56
- **License:** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- **Changes:** The source photograph was used only as a visual reference for an
  original, stylized smart-ring illustration. The photographed hand, setting,
  and pixels are not present in the finished icon.

`Bezahlring-CC0.jpg` is retained here as the traceable source image.
`AppIcon-1024.png` in the asset catalog is the full-bleed 1024 × 1024 App Store
icon master. Apple applies the platform-specific corner mask automatically.
